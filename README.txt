================================
    🎤 合成大歌姬 🎵
================================

【游戏简介】
合成大歌姬是一款基于"合成大西瓜"玩法的角色合成游戏。
将相同角色的小球合成更大的球，最终合成初音未来！

【如何启动】
方式一：双击 start.bat
方式二：双击 start.py
启动后自动打开浏览器，访问 http://localhost:8080

【前提条件】
需安装 Python 3
下载地址：https://www.python.org/downloads/
安装时务必勾选 "Add Python to PATH"

【音乐系统】
- 合成出某个角色后，解锁她的所有歌曲
- 右侧面板可浏览和播放已解锁歌曲
- 底部进度条可拖拽调整播放进度
- 游戏结束后解锁歌曲全部重置
